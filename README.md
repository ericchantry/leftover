# LEFTOVER

A tiny RPG about a lost left sock under the couch. Undertale-style talk-or-fight battles,
Zelda-style action, five bosses, and an original chiptune soundtrack. Plays on phones (touch pad)
or PC (WASD + Space).

The whole game is one self-contained `index.html` (no build step, no dependencies).
Hosted as a Render static site with publish directory `.`.
